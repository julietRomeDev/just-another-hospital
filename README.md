# JustAnother Hospital
Sistema de Simulación de Gestión Hospitalaria.

## Req
- [Laragon](https://laragon.org/) o [XAMPP](https://www.apachefriends.org/)

## Como configurar
1. **Instalar** Laragon o XAMPP
2. **Iniciar Servicios**: Ejecutar APACHE y MySQL
3. **Inicializar entorno**: Ejecutar el script `init.cmd`.
