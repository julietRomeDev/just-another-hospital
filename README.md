# JustAnother Hospital
Sistema de Simulación de Gestión Hospitalaria.

## Req
- [Laragon](https://laragon.org/) o [XAMPP](https://www.apachefriends.org/)
- [Python](https://python.org)

## Como configurar
1. **Instalar** Python
2. **Instalar** Laragon o XAMPP
3. **Iniciar Servicios**: Ejecutar APACHE y MySQL
4. **Inicializar entorno**: Ejecutar el script `init.cmd`.
